# Contributing to Muninn Labs

Thank you for contributing to Muninn Labs.

## Getting Started

1. Fork the repository and branch from `main`.
2. Keep pull requests small, atomic, and scoped to a single logical change.
3. Add or update tests covering your changes.
4. Ensure all local builds, tests, and linters pass before requesting review.

## Commit Messages

We follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` — a new feature
- `fix:` — a bug fix
- `docs:` — documentation changes
- `refactor:` — code restructuring without behavior change
- `test:` — adding or updating tests
- `chore:` — maintenance tasks

## Code Review

All changes to `main` require maintainer review and passing CI checks.
